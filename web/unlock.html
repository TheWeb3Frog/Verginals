Recover your coins

When you etched your coin, its ticker price was locked for four years. This is where you watch the clock and take it back. How the lock works.

Find your lock

Paste the transaction that created your coin. Nothing secret goes here, and nothing is sent anywhere: this only reads what is already public on the chain.

Take it back

Your key never leaves this page. The transaction is built and signed here, in your browser, and only the finished signature is sent to the network. Nobody, including this site, sees the key itself.

Lost the key and nothing can help you, which is the whole point of a lock only you can open. Lost the transaction id but kept the key? The command line can still find it: node src/cli.js unlock --wif KEY --locktime DATE --to ADDRESS

This page is not the only way. The same recovery works as a file you keep, with no internet and no website, and from a copy that does not depend on this server at all: https://theweb3frog.github.io/Verginals/ It is in the public repository too, so it travels in every clone anybody has made of it.
